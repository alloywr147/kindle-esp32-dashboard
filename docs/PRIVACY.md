# 本地配置与发布边界

本仓库采用显式选择源码文件的方式整理，没有复制整个工作区。

不包含：家庭Wi-Fi名称/密码、设备访问密钥、SSH私钥/公钥及known_hosts、设备MAC、
原Flash/现有应用备份、真人待办、私有二维码、网络日志、设备配置和真实屏幕截图。
地址示例使用可替换的 `192.168.1.50`，不是原部署地址。
Kindle 系统文件和 KOReader 运行时也不包含；运行时从官方取得。

包含的 `weather-root.pem` 是公开根证书，不是私钥。
`calendar.dat/idx` 是公开日期对应的历法生成数据，已检查不含待办和网络字段。

使用时会产生：

- ESP NVS：家庭Wi-Fi配置和随机配网热点密码。
- ESP LittleFS：待办、显示选项、天气缓存；这些仅在设备上写入。
- Kindle：`kt2-config.json`、待办缓存、运行日志。
- 电脑：`private/` 中的备份和本地安装目录。

`.gitignore` 是防误提交辅助，不是自动脱敏工具。发布时只提交源码目录，先运行
`python tools/check_release.py`，再人工核对 Git 待提交列表，不要提交上述本地数据。

当前服务依用户选择不设访问密钥。保留JSON请求和来源检查，但不等于用户认证。
只用于可信家庭局域网；不要直接映射到公网。本仓库未为远程访问设计账户体系。
