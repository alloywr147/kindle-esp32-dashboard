2026-10-17：KT2 / 5.12.2.2 与4MiB ESP32-C3 Mini。

- 官方KOReader v2026.07.1 kindlepw2 包校验并实际运行，600×800中文全屏，无浏览器栏。
- 真人手机编辑、Kindle手指勾选/取消、手机同步，用户确认通过。
- 放大勾、完整方框、首页宜忌冲煞与下移后的点击区域已部署；首页实际抓屏无重叠。
- 12项模型回归、复选框绘图检查、按小时/零点版本策略测试通过。
- 临时中断 Kindle→ESP HTTP 后不误报保存成功，恢复后自动同步。
- 两小时低频观察25样本、HTTP失败0、未检测ESP重启；不代表已验证多日运行或续航。
- 持续运行设置和手动退出恢复已验证；实际手指出口与所有边缘触点未系统验收。
- ESP应用升级后原待办/配置保持，免密及网页直接删除经真实浏览器验证。
- 用户报告独立供电测试成功，电脑实际关机的最终验收没有单独明确确认。

## 发布副本与原部署的区别

- 删除固定家庭IP、电脑路径和SSH依赖，地址改配置。
- Kindle 安装目录由开发期目录统一成 `/mnt/us/kt2-dashboard/native`。
- 默认关闭仅用于开发验证的本地测试命令循环。
- 不打包旧浏览器隐藏工具栏路线、越狱工具、SSH组件、后台监控或私人截图。
- 新增通用备份/刷写和离线安装目录生成器；工具不会在构建时自动刷设备。

这些通用化改动需要在复刻者设备上重新验收。原部署通过不等于本发布目录已经重新刷入原设备。
当地源码构建、文件系统构建、隐私扫描和生成器检查的结果见发布目录外的本地整理报告。
